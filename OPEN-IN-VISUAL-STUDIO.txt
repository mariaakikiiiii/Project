GameOn — Open in Visual Studio

1. Extract the ZIP.
2. Install Visual Studio 2022 (17.8 or newer) with the ASP.NET and web development workload and .NET 8 SDK.
3. Double-click GameOn.sln. The backend project is included.
4. Follow README.md to prepare SQL Server and securely configure ConnectionStrings:GameOn. Never put database passwords in source files.
5. Run the API using HTTPS on port 7043 as described in README.md.
6. For React, open a terminal in frontend and run npm ci, then npm run dev (Node.js 22+).

The SQL scripts are in database/. Frontend source is in frontend/.
Builds and security middleware smoke tests passed in the cloud. SQL Server and end-to-end database workflows have not yet been validated; see docs/validation.md.

Generated dependencies and build output are omitted; npm and NuGet restore them.

PLATFORM UPGRADE: read docs/UPGRADE.md. Existing databases must apply 07-platform-upgrade.sql once in SQLCMD Mode. Do not rerun 01-schema.sql. Online cash-out needs your merchant-provider integration; Maps Embed and recovery email need secure configuration.

GIN401 EDITION: after version 7, install 09-categories-and-events.sql once in SQLCMD Mode, then 10-user-analytics-seed.sql. Read docs/GIN401.md. All 17 sports/activities and the multi-step event form are included. Whish execution is skipped per request.
